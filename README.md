# Анализ вакансий Java-разработчиков

Проект посвящён анализу вакансий Java-разработчиков: подсчёту востребованных навыков, сравнению результатов разных способов обработки данных и исследованию зарплат.

## Данные

Подготовленный датасет содержит 6 907 вакансий. Исходные CSV-файлы не включены в Git. Подготовленный датасет и результаты MapReduce хранятся в RustFS.

## Реализация

- `src/prepare_data.py` — подготовка данных.
- `src/mapreduce.py` — MapReduce-подсчёт навыков и комбинаций.
- `src/mapreduce_chunked.py` — чтение данных из RustFS чанками разных размеров и профилирование.
- `src/duckdb_analysis.py` — независимый SQL-подсчёт через DuckDB.
- `src/compare_results.py` — сравнение результатов MapReduce и DuckDB.
- `src/salary_analysis.py` — анализ качества данных о зарплатах.
- `src/salary_by_region.py` — сравнение зарплат по регионам.
- `src/skills_by_region.py` — анализ востребованных навыков по регионам.
- `src/salary_skill_combinations.py` — анализ зарплат в зависимости от навыков и их комбинаций.
- `src/build_report.py` — формирование итогового PDF-отчёта.

## Результаты

Каталог `results/` содержит таблицы частот навыков и их комбинаций, результаты профилирования, а также данные регионального и зарплатного анализа.

MapReduce обработал 6 907 вакансий при каждом из трёх размеров чанка: 256 КБ, 1 МБ и 4 МБ. Получено 1 343 уникальных навыка, 20 635 пар и 137 489 троек.

Результаты MapReduce полностью совпали с результатами DuckDB. Время выполнения и использование памяти измерялись для каждого размера чанка в трёх запусках.
