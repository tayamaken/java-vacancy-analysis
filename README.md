# Анализ вакансий Java-разработчиков

Учебный проект по анализу вакансий с использованием RustFS, MapReduce и DuckDB.

## Данные

Подготовленный датасет содержит 6 907 вакансий. Исходные CSV-файлы не включены в Git.

## Реализация

- `src/prepare_data.py` — подготовка данных.
- `src/mapreduce.py` — MapReduce-подсчёт навыков и комбинаций.
- `src/mapreduce_chunked.py` — чтение из RustFS чанками разных размеров и профилирование.
- `src/duckdb_analysis.py` — независимый SQL-подсчёт через DuckDB.
- `src/compare_results.py` — сравнение результатов MapReduce и DuckDB.
- `src/salary_analysis.py` — анализ качества данных о зарплатах.
- `src/salary_by_region.py` — сравнение зарплат по регионам.
- `src/skills_by_region.py` — анализ востребованных навыков по регионам.
- `src/salary_skill_combinations.py` — связь комбинаций навыков с зарплатами.

## Результаты

Каталог `results/` содержит таблицы частот навыков, пар и троек, профилирования, регионального и зарплатного анализа.

MapReduce обработал 6 907 вакансий для каждого из трёх размеров чанка: 256 КБ, 1 МБ и 4 МБ. Получено 1 343 уникальных навыка, 20 635 пар и 137 489 троек.

## Ограничения

В зарплатном анализе используются только вакансии с валютой RUB. В исходных данных есть пропущенные зарплаты и отдельные подозрительно низкие значения, поэтому результаты требуют осторожной интерпретации.
